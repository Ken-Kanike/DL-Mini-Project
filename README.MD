# Music Genre Classification Using LSTM-Based Deep Learning on Audio Features

## Deep Learning Mini Project

### Project Overview
This Deep Learning mini project focuses on automated music genre classification using audio signal processing and Recurrent Neural Networks (RNN / LSTM). By extracting rich temporal and spectral representations—including Mel-Frequency Cepstral Coefficients (MFCCs), Spectral Centroid, Chromagram, and Spectral Contrast—from audio samples, the model captures sequential musical structures across genres to perform accurate multi-class classification.
